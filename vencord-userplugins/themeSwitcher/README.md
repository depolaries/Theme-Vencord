# ThemeSwitcher

Switch MyTheme presets instantly from a compact color button in Discord's
top-right titlebar. The plugin also keeps the settings selector, Vencord
Toolbox actions, and `/vtheme` command as alternative controls.

Custom distributions should be rebuilt after Vencord updates replace the
installed bundle.

Switches the local `MyTheme-Active.css` preset without restarting Discord.

Available from:

- Vencord Settings -> Plugins -> ThemeSwitcher -> Preset
- Vencord Toolbox actions
- `/vtheme preset:<name>`

The local `Base.css` and preset files must be installed by `VTheme install` once.
